# sands

<p align="center">
  <img src="./assets/readme/hero.jpg" width="100%" alt="Sands: calendar management in plain language — creates, queries, modifies, and deletes events across personal and work calendars">
</p>

Sands reads across personal and work calendars, resolves natural-language time references to ISO 8601 ranges, and handles recurring events with scope control. Work events appear as busy blocks with titles suppressed. Travel time is computed via Google Places Distance Matrix API. Every action supports undo within 24 hours.

**Capabilities:**
- Natural-language date/time parsing
- Multi-calendar read/write with privacy scoping
- Travel time computation via Google Places
